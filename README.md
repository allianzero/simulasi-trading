# SIMULASI TRADING

Virtual crypto trading simulator in Indonesian Rupiah.

- Starting capital: Rp5,000,000 (virtual money)
- Live prices in IDR from CoinGecko public API
- Buy and sell BTC, ETH, BNB, SOL, XRP, DOGE, ADA, TRX
- Portfolio tracking with profit/loss, portfolio value chart, and transaction history
- All data stored locally in the browser (localStorage)

This is a simulation with virtual money. No real money is involved and this is not investment advice.
